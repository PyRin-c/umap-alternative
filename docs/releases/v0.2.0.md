# umap-alternative v0.2.0 プレビュー

v0.2.0 は、近傍探索とレイアウト更新の実行時間を短縮するリリースです。

- 密な入力の近似近傍探索では、投影と候補間距離の計算を SIMD 化し、学習グラフを Rust 内で構築する経路を追加しました。
- 疎なユークリッド入力では、学習・変換・更新の近傍探索に非ゼロ要素の列インデックスを活用します。
- 互換レイアウトでは、2次元の座標更新と負例の選択を高速化しました。

Windows x64、CPython 3.13.12、1スレッドで測定した疎1,024行のケースでは、変換の中央値が v0.1.0 の78.80 msから23.10 msになりました。測定した密2ケースと疎1ケースでは、グラフと学習・変換座標が v0.1.0 とビット一致しました。公式の `umap-learn 0.6.0` との互換性はケースごとの検証に基づき、密な入力の近似グラフや、C ABI の同距離候補の順位には既知の差があります。

| 配布物 | 対象 |
| --- | --- |
| `umap_alternative-0.2.0-cp*-win_amd64.whl` | Windows x64、CPython 3.10〜3.15 |
| `umap_alternative-0.2.0-cp*-manylinux_2_34_x86_64.whl` | Linux x86-64、glibc 2.34 以上、CPython 3.10〜3.15 |
| `umap-alternative-cabi-0.2.0-win-x64.zip` | Windows x64。DLL、MSVC 用 `.lib`、C ヘッダーとサンプル |
| `SHA256SUMS` | 配布ファイルの SHA-256 |

Python では、OS と CPython のバージョンに合った wheel を取得してインストールします。以下は Windows x64 の CPython 3.10 の例です。

```powershell
py -3.10 -m pip install ./umap_alternative-0.2.0-cp310-cp310-win_amd64.whl
```
