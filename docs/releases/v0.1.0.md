# umap-alternative v0.1.0 プレビュー

UMAP を Rust で独立実装した `umap-alternative` の初回プレビューです。Python から埋め込みやグラフを扱う wheel と、Windows アプリから C ABI を呼び出す DLL を GitHub Releases で配布します。

| 配布物 | 対象 |
| --- | --- |
| `umap_alternative-0.1.0-cp*-win_amd64.whl` | Windows x64、CPython 3.10〜3.15 |
| `umap_alternative-0.1.0-cp*-manylinux_2_34_x86_64.whl` | Linux x86-64、glibc 2.34 以上、CPython 3.10〜3.15 |
| `umap-alternative-cabi-0.1.0-win-x64.zip` | Windows x64。DLL、MSVC 用 `.lib`、C ヘッダーとサンプル |
| `SHA256SUMS` | 配布ファイルの SHA-256 |

Python では、OS と CPython のバージョンに合った wheel を取得してインストールします。以下は Windows x64 の CPython 3.10 の例です。

```powershell
py -3.10 -m pip install ./umap_alternative-0.1.0-cp310-cp310-win_amd64.whl
```

```python
from umap_alternative import UMAP

points = [[0, 0], [1, 0.1], [0.2, 1.3], [1.7, 2.1], [2.2, 0.4]]
embedding = UMAP(n_neighbors=3, n_jobs=1, random_state=42, compatibility_layout=True).fit_transform(points)
```

公開版 `umap-learn 0.6.0` との値と型の照合は、固定した参照環境と検証ケースに基づきます。近似探索の一部の経路は未実装で、C ABI には同距離候補の順位で既知の差があります。ParametricUMAP の複数行の学習には TensorFlow と Keras が必要です。[対応範囲と検証記録](https://github.com/PyRin-c/umap-alternative/blob/v0.1.0/reference/implementation_status.md)
