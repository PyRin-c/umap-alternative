# Nine-row recursive star placement in UMAP 0.6.0

The [rounding follow-up](modern_recursive_rounding_reference.md#exact-contraction-expansion-and-fitted-checkpoints)
matches the archived star through contraction, expansion, and fitting
bit for bit. The measurements below describe the earlier implementation.

The [fixture generator](generate_modern_recursive_star_fixture.py)
records public `label_propagation_init`, `simplicial_set_embedding`,
`UMAP.fit` and `UMAP.fit_transform` outputs. It suppresses warnings and
reports only the exception class if a fit or supplied-stage call fails.

## Placement precision

The previous port and the pinned wheel agreed on the graph and caller
RNG. The discrepancy appeared before the nine-row optimizer. At root
budget eleven the deeper three-row stage runs fifteen epochs and the
expanded rows are nearly coincident. Feeding two versions of that
placement into the same sampler amplified their `2.236e-7` input
difference to `2.291e-4` at epoch 1, the first effective attraction.

The scalar probes isolate expansion from the Procrustes rotation. They
supply the public child layout and an independent weighted graph, so
each row's output depends on the averaging and centering arithmetic.
All twelve arrays match bit for bit when each edge product rounds to
float32 and the row sums, degree normalization, midpoint and centering
stay in float64. The previous arithmetic matched three arrays exactly.

The replay keeps those precision boundaries and rounds the centered
layout before Procrustes alignment. It also centers the float64 PCA
sketch input with float32 feature means, averages each part in float64,
and normalizes and symmetrizes the transition matrix in float64 before
storing its weights. The robust span rounds after subtracting the two
percentiles. The scale is applied before the final coordinate cast.
The graph and sampler stay on the existing path.

## Frozen optimizer

Eight nine-row replays freeze the public epoch-zero layout and caller
seed. The inputs bracket budgets 10, 11 and 12 and the float32 weights
immediately below and above one half. They also vary an anchor by one
float32 step and exercise both transition and fuzzy-union placement and
negative rates zero and one. Explicit-init jitter is supplied as zero
to preserve coincident rows. The port matches all 96 public checkpoint
arrays bit for bit and matches the RNG cursor, cache and next four words
for each replay.

In the budget-eleven replay, the one-step anchor change produces a
`4.471e-8` initial difference and a `3.711e-6` difference after epoch 1.
With attraction-only half-weight edges, the weight immediately below
one half delays the corresponding attraction past epoch 2. The maximum
difference from the exact-half run at epoch 2 is `0.006893`. The same
frozen start at rate one first diverges from rate zero at epoch 3.

## Before and after

Maximum absolute coordinate differences agree on Windows and Ubuntu WSL.
The raw archived layout comes from `recursive_init` on the public fitted
CSR with the same features, seed, ratio, threshold and budget.

| Case | Before | After |
| --- | ---: | ---: |
| Archived eleven-epoch star, before outer rescaling | `9.609e-5` | `4.296e-7` |
| Archived eleven-epoch star, fitted coordinates | `0.00673771` | `2.337e-5` |
| Archived star, default positive coarse budget | `1.324e-5` | `7.630e-6` |
| Archived four-level transition | `2.677e-5` | `1.073e-5` |
| Fresh one-level star, budget 11, rate 0 | `4.769e-7` | `4.769e-7` |
| Fresh two-level star, budget 10, rate 0 | `2.978e-5` | `9.954e-6` |
| Fresh two-level fuzzy-union star, budget 11, rate 0 | `3.958e-5` | `4.292e-6` |

Seven fresh fit recipes match graph and RNG bits through both public
fit methods. Their largest fitted error is `9.954e-6`. The archived case
now has an asserted `3e-5` bound through both methods. The existing
verified coordinate tolerances also pass. Its fitted coordinate array
still has a small nonzero residual.

The two hosts generated byte-identical fixtures and each passed 2,806
installed-wheel tests with zero expected failures, 197 locked Rust
tests with eight ignored, formatting and warning-denied Clippy.

## Reproduce

Use the pinned reference environment separately from the project wheel.
Keep Cargo targets and wheel builds on C: or under the WSL home, set
`CARGO_BUILD_JOBS=2` and use one numerical thread. Replace `ubuntu`
with `windows` for the Windows fixture. The
[previous build commands](modern_recursive_transition_reference.md#reproduce)
also apply.

```sh
uv run --project reference --locked python -B -W ignore reference/generate_modern_recursive_star_fixture.py \
  --output reference/fixtures/umap-learn-0.6.0-modern-recursive-star-ubuntu-x86_64.json
uv run --no-sync python -B -m pytest -p no:cacheprovider -q \
  tests/test_modern_recursive_star.py tests/test_modern_recursive_coarse.py
```
